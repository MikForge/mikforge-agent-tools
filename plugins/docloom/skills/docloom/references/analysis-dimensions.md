# 熵分析维度详解


## 一、违规频率统计

| 维度 | 说明 |
|------|------|
| 条目级统计 | 每个 checklist 条目的触发次数、严重/重要/轻微分布 |
| 文档类型分组 | 按 PRD / 设计 / 计划分别统计 |
| Top N | 高频违规排名，标记为"规范优化候选" |

## 二、修复模式分析

| 维度 | 说明 |
|------|------|
| 方案聚类 | 同一条目的修复方案相似度，若 >80% 用同一方案 → 沉淀为规范推荐做法 |
| 反复修复 | 同一问题多轮 fix 才关闭的条目 → 规范表述不够清晰 |

## 三、修复类型分布

| 类型 | 定义 |
|------|------|
| 结构性 | 缺章节、缺必需元素 |
| 表达性 | 措辞模糊、TBD 占位符、需求不可验证 |
| 格式性 | 链接格式、编号、引用标记 |

## 四、跨文档类型对比

| 指标 | 说明 |
|------|------|
| 平均问题数/文档 | 每种类型的违规密度 |
| 首次审查通过率 | 新文档不经修复直接通过的比例 |
| 熵值趋势 | 上升 / 平稳 / 下降 |

## 五、趋势分析

按周统计提交数、平均问题数、熵值变化方向，识别规范优化是否生效。

## 六、阻塞项分析

auto-fix 模式中标记为 `阻塞` 的问题，按原因分类：缺领域知识 / 规范冲突 / 规范缺失。

## 七、规范变更影响追踪

当 standard 文件被修改后，对应 checklist 条目的触发率变化：有效（↓）/ 无效（→或↑）。

## 八、优化建议优先级

| 优先级 | 定义 |
|--------|------|
| P0 | 高频 + 严重 + 反复修复 |
| P1 | 高频 or 严重，修复方案已收敛 |
| P2 | 低频但趋势上升，或仅轻微 |
